# Sổ tài chính gia đình

Giao diện web tối ưu cho iPhone để ghi thu chi, theo dõi thẻ tín dụng / Apple Pay, tiền mặt, tài sản và vay nợ.

- Dữ liệu **không** nằm trong kho này: ứng dụng đọc/ghi Google Sheet riêng qua API Apps Script, yêu cầu mã bí mật.
- Nhập bằng giọng nói tiếng Việt (Web Speech API – Safari trên iPhone).
- Mở lần đầu: nhập địa chỉ API và mã bí mật (lấy từ hàm `taoMaBiMat` trong Apps Script); mã chỉ lưu trên thiết bị.
